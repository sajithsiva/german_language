# Unterricht

## Meaning
**Unterricht** means:
- lesson  
- class  
- instruction / teaching  

---

## Word Split (Etymology)

**Unterricht = unter + richten**

- **unter** → under / among  
- **richten** → to direct, set right, arrange, judge  

👉 Historically, **unterrichten** meant:
> “to set things right among people” → “to teach / instruct”

---

## Modern Usage

In modern German, the split is not consciously felt.

**Unterricht = a lesson or class**

---

## Grammar

- **der Unterricht** (masculine)
- Usually **uncountable**

---

## Examples

- Ich habe heute **Unterricht**.  
  → I have class today.

- Der Unterricht beginnt um 8 Uhr.  
  → The lesson starts at 8.

---

## Related Verb

- **unterrichten** → to teach  

Example:
- Ich **unterrichte** Deutsch.  
  → I teach German.

---

## Important Distinction

- **der Unterricht** → the class / lesson  
- **unterrichten** → to teach  

---

## Memory Tip

- **richten** = to set right  
- A teacher “sets things right” in your understanding  

👉 **Unterricht = teaching / lesson**
